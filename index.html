2 เมนูด้านล่าง 5 หน้า

⚙️ จัดการทีม

  1. เลือกวัน / เวลาเริ่ม / นาทีต่อแมตช์
  2. ติ๊กทีมที่ลงแข่ง
  3. เลือกรูปแบบ + แตะสีทีมหรือดึงคันชักสุ่มคู่เปิด แล้วกดบันทึก / อัปเดต
  4. หลังสร้างแล้ว เปลี่ยนคู่เปิดได้ที่ตารางแข่งเช่นกัน
  5. แชร์รูปแบบลงทะเบียน LINE ได้
  6. โหมดอัปเดต: วางกลุ่มใหญ่ + กลุ่มย่อย → รวมชื่อคัดลอกกลับ LINE
เห็นเมนูนี้เฉพาะ Admin ที่อนุมัติแล้ว

📅 ตารางแข่ง

  1. เลือกวันจาก dropdown
  2. ดูคู่แข่ง + เวลาแต่ละแมตช์
  3. Admin: เลื่อนขึ้นเป็นคู่เปิด / เพิ่ม / ลบแมตช์
  4. กด แชร์ LINE เพื่อส่งรูปตาราง

🏟️ จัดตำแหน่ง

  1. เลือกทีม (ครบทุกสี)
  2. เลือกแผน เช่น 2-3-1
  3. คลิกวงกลมบนสนาม → พิมพ์ชื่อ → Enter
  4. แชร์รูปแผนได้ทันที
ชื่อบนสนามไม่บันทึกลงระบบ — รีเฟรชแล้วหาย

✏️ บันทึกผล + 🏆 คะแนน

  1. บันทึกผล: กด +/− หรือพิมพ์สกอร์
  2. ตารางคะแนนคำนวณให้อัตโนมัติ
  3. เรียงตามแต้ม / ผลต่างประตู
  4. แชร์รูปผลหรือตารางคะแนนได้

3 สมัคร Admin / เข้าสู่ระบบ

สมัครใช้งาน

  1. กด เข้าสู่ระบบ → แท็บ สมัคร Admin
  2. กรอกชื่อ อีเมล รหัสผ่าน
  3. รอ Superadmin กดอนุมัติ
  4. อนุมัติแล้วจึงจัดการตารางได้

ลืมรหัสผ่าน

  1. ในหน้าเข้าสู่ระบบ กด ลืมรหัสผ่าน
  2. กรอกอีเมล → เปิดลิงก์ในอีเมล
  3. ตั้งรหัสใหม่ → ล็อกอินอีกครั้ง

4 แชร์ไป LINE

ข้อความ / รูป

  • กดแชร์แล้วระบบคัดลอกอัตโนมัติ
  • เปิด LINE → วางในแชทได้เลย
  • อยากได้ไฟล์ค่อยกด ดาวน์โหลดรูป

วางยังไง

  • PC: Ctrl+V ในแชท LINE
  • มือถือ: กดค้างในแชท → วาง
  • อยากได้ไฟล์ค่อยกด ดาวน์โหลดรูป
